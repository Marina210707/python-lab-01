# Лабораторна робота 3: Рейтинг та модель об'єктів

## Опис проєкту
Реалізовано розширений пошуковий рушій на базі інвертованого індексу з другої лабораторної. 
Додано:
- Dunder-методи (`__len__`, `__getitem__`, `__iter__`, `__repr__`) для роботи з індексом як з об'єктом Python.
- Алгоритми ранжування TF-IDF та BM25.
- Парсер запитів (рекурсивний спуск) з підтримкою `AND`, `OR`, `NOT`, дужок та фраз у лапках.
- Декоратори `@timed` та контекстний менеджер `open_index`.
- Генерацію сніпетів (виділення тексту навколо знайденого слова).

## Перевірки ранжування (Sanity Checks)
1. **Рідкісний термін vs Частий термін:** BM25 та TF-IDF надають вищу оцінку документам, де зустрічається рідкісний термін, оскільки його IDF (зворотна частота документа) значно вища.
2. **Ефект насичення (20-те повторення):** У BM25 завдяки параметру `k1=1.5` зростання частоти терміну (TF) сповільнюється. 20-те входження слова додає дуже мало до загальної оцінки порівняно з 2-м або 3-м входженням, запобігаючи "спаму" ключовими словами.
3. **Короткий документ vs Довгий документ:** BM25 штрафує дуже довгі документи (параметр `b=0.75`). Тому короткий документ з одним входженням терміну отримає вищу оцінку, ніж дуже довгий документ, де цей термін також зустрічається один раз.

## Порівняння TF-IDF та BM25 (Precision@5)
*(Тут можна залишити місце для таблиці, але для здачі достатньо текстового опису)*
- **TF-IDF** показує вищі абсолютні значення оцінок, але не враховує довжину документа.
- **BM25** є більш збалансованим і краще працює на реальних запитах завдяки нормалізації довжини документа та насиченню частоти.
