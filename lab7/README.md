# Лабораторна робота 7: Веб-пошук (FastAPI)

## Опис проєкту
Це продовження пошукового рушія `findindex`. У цій версії реалізовано веб-інтерфейс на базі **FastAPI**. 
Додано:
- REST API для пошуку (`/search`), статистики (`/stats`), перевірки стану (`/health`) та перегляду документів (`/docs/{doc_id}`).
- Валідацію даних на вході та виході через **Pydantic**.
- HTML-сторінку з полем пошуку (Jinja2).
- Логування помилок.
- Docker-контейнеризацію.
