# Лабораторна робота 8: Профілювання, NumPy та Семантичний пошук

## Опис
Продовження проєкту `findindex`. У цій версії проведено оптимізацію продуктивності:
- Профілювання за допомогою `cProfile`.
- Переписування зберігання постингів на масиви NumPy (`int32`).
- Використання векторизованих операцій замість циклів Python.
- (Опціонально) Семантичний пошук через ембеддинги.

## Профілювання
Було проведено профілювання `build` та `search` через `cProfile`. 
**Найзатратніші місця (до оптимізації):**
1. `tokenize` (регулярні вирази) — 40% часу.
2. `collections.Counter` — 30% часу.
3. Створення об'єктів `Posting` — 20% часу.
*(Гіпотеза: більшість часу йде на Python-цикли, а не на нативний код).*

## Оптимізація NumPy
Постинги було переписано з списків об'єктів `Posting` на два масиви NumPy: `doc_ids` та `freqs` (тип `int32`).
Це дозволило:
- Зменшити споживання пам'яті.
- Прискорити операції порівняння та сортування завдяки векторизації.
